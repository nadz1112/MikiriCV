# Cách làm việc

- Xây dựng tăng dần, MỘT trang/tính năng mỗi lần; xong và chạy được mới sang phần tiếp theo.
- Code mới phải khớp chính xác cấu trúc hiện có; không sửa, đổi tên hay di chuyển file không liên quan.
- Trước khi sửa, đọc file hiện có và theo đúng phong cách của nó.
- Thay đổi API/schema phải đối chiếu Chương 5 và nói rõ nếu cần cập nhật tài liệu.
- Khi yêu cầu mâu thuẫn với tài liệu hoặc ngoài phạm vi MVP, nêu rõ thay vì tự quyết.
- Khi bàn giao nhiều file, nêu danh sách file đã thêm/sửa.
